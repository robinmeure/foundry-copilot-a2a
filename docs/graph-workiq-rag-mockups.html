What happens after import?

  1. Validate file and scan for threats.
  2. Choose an extractor: Document Intelligence layout for scanned or table-heavy PDFs, local parsers for simple files.
  3. Keep headings, pages, and tables; split large tables by rows with the header repeated.
  4. Chunk and embed in the WebAPI.
  5. Index text, vectors, and ownership.
  6. Make the document available to chat.
Proposed MVP: PDF (including scanned), DOCX, TXT, Markdown, CSV; 20 MiB and 300 pages per file. These are new RAG limits, not existing attachment limits.
